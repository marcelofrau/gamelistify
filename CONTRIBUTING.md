# Contributing

## Workflow

1. start from `main`
2. create feature branch
3. keep changes focused
4. run build and tests locally
5. update docs when behavior changes

## Branch naming

- `feat/<name>`
- `fix/<name>`
- `chore/<name>`
- `docs/<name>`

## Commands

```powershell
dotnet build Gamelistify.sln -c Debug
dotnet test Gamelistify.sln -c Debug
```

## Standards

- keep documentation in English
- preserve user data safely
- create backups before destructive file writes
- prefer small, reviewable changes
