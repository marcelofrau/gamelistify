# Icon Set Sync

Gamelistify follows the same local-development icon workflow used in XB Homebrew Vault.

## Local Path

```text
D:\workspace\_non_work_\icons8-personal-set
```

## Recommended Approaches

1. local path only during development
2. submodule if icons ever get a dedicated repository
3. subtree only if redistribution rights are confirmed

## Checklist Before Committing Icons

- confirm redistribution rights
- add attribution notes
- keep filenames aligned with `docs/assets-guide.md`
- avoid absolute paths inside project files
