# Theme Direction

## Creative Goal

Gamelistify should feel like a focused maintenance workstation for retro libraries.

Visual reference:

- image-heavy metadata workflow
- dark operator console feel
- subtle nostalgia from scraper tooling
- distinct identity, not a clone of any existing scraper UI

## Product Style Direction

The application will lean toward **tool/workbench** rather than **catalog/media browser**.

That means:

- denser information layout
- stronger status indicators
- clearer action hierarchy
- less decorative empty space
- panels that feel operational, not storefront-like

## Theme Tokens

| Token | Purpose |
|------|---------|
| `WorkbenchBg` | Main window background |
| `WorkbenchSurface` | Panels and cards |
| `WorkbenchSurfaceAlt` | Secondary surfaces |
| `WorkbenchAccent` | Primary interactive accent |
| `WorkbenchAccentGlow` | Hover and focus emphasis |
| `WorkbenchWarning` | Warning state |
| `WorkbenchDanger` | Destructive state |
| `WorkbenchSuccess` | Success state |
| `WorkbenchBorder` | Dividers and outlines |
| `WorkbenchText` | Primary text |
| `WorkbenchTextMuted` | Secondary text |

## Early Palette Direction

- charcoal and graphite backgrounds
- amber-orange highlight family
- restrained cool blue support color
- pale neutral text
- warm contrast for selected states

## Typography Direction

- modern readable UI sans for body text
- stronger industrial/technical face for headings if licensing allows
- monospaced font for logs and paths

## Layout Behavior

- grid-heavy desktop composition
- resizable panes
- compact filters
- strong selected-row state
- large image preview frame in detail pane
