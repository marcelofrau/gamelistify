# Attributions

## Icons

All UI icons are rendered from the **Numix icon theme** by the Numix Project.

- Upstream: <https://github.com/numixproject/numix-icon-theme>
- License: **GPL-3.0** (matches this application's license)

Icons are exported to PNG at 32px into `Assets/Views/` and referenced via
`avares://Gamelistify/Assets/Views/...`. The local source clone used for renders
lives at `F:\workspace\numix-icon-theme\` (outside this repository).
